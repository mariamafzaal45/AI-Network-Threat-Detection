# AI Cyber Threat Detection using Machine Learning

## Overview

This project implements a Machine Learning-based Cyber Threat Detection system capable of identifying malicious network activities from security-related data. The project includes data preprocessing, model training, evaluation, and configuration files required to reproduce the results.

The goal is to demonstrate an end-to-end Machine Learning workflow for cybersecurity applications while following good software engineering practices.

---

## Project Structure

```text
AI-Cyber-Threat-Detection-ML/
│
├── train_model.py             # Train the machine learning model
├── evaluate_model.py          # Evaluate the trained model
├── ML_Threat_Detection.ipynb  # Jupyter Notebook implementation
├── config.yaml                # Configuration settings
├── requirements_ml.txt        # Required Python libraries
└── README.md                  # Project documentation
```

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/AI-Cyber-Threat-Detection-ML.git
```

Move into the project directory:

```bash
cd AI-Cyber-Threat-Detection-ML
```

Install the required dependencies:

```bash
pip install -r requirements_ml.txt
```

---

## Usage

Train the model:

```bash
python train_model.py
```

Evaluate the model:

```bash
python evaluate_model.py
```

Or open the notebook:

```bash
jupyter notebook ML_Threat_Detection.ipynb
```

---

## Configuration

Project settings can be modified in:
